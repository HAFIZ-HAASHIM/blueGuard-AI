# Contributing to BlueGuard AI

Thank you for contributing to **BlueGuard AI**!

---

## 🛠️ Local Development

1. **Clone Repo:**
   ```bash
   git clone https://github.com/HAFIZ-HAASHIM/blueGuard-AI.git
   cd blueGuard-AI
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run Dev Server:**
   ```bash
   npm run dev
   ```
