# Security Policy for BlueGuard AI

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting Security Vulnerabilities

If you discover a vulnerability or security risk within BlueGuard AI:
1. Please do not create public issues.
2. Report the vulnerability directly to: [haashimmuhammad7@gmail.com](mailto:haashimmuhammad7@gmail.com).
3. We will respond within 48 hours to assess and patch any confirmed issues.
